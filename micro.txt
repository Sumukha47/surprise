1. List local branches
git branch
git branch --list

2. Create a new branch
git branch branch_name

3. Switch to a branch
git switch branch_name
git checkout branch_name

4. Create and switch to a branch
git checkout -b branch_name

5. Push a branch to remote repository
git push alias_name branch_name

Example
git push origin master
git push origin main

6. List remote branches
git branch -r

7. List local and remote branches
git branch -a

8. Pull a branch from remote repository
git pull alias_name branch_name

Example
git pull origin master
git pull origin main

9. Delete a local branch
git branch -d branch_name

10. Force delete a local branch
git branch -D branch_name

11. Delete a remote branch
git push alias_name -d branch_name

12. Rename a branch
git branch -m old_branch_name new_branch_name
